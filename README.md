# MR Detailing Academy — Premium Telegram Mini App (React)

## Старт
```bash
npm i
npm run dev
```

## Сборка
```bash
npm run build
npm run preview
```

## Telegram
- Задеплой папку `dist/` на хостинг
- Укажи URL в BotFather → Web App
- Открывай из Telegram — SDK сам расширит WebApp


## Mobile/Telegram layout
- Layout сделан mobile-first (grid + safe-area)
- В Telegram WebView лучше тестировать прямо внутри Telegram
